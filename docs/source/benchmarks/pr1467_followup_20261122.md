## Hypotheses, controls and gates

1. **H1: feasible CatBoost tuning, fabert.** Fixed, recorded proposals around
   the incumbent; compare three-fold search against two-fold search with a
   three-fold finalist confirmation. Calibrate fresh evaluation cost with the
   initial tuner evaluation; record fit, prediction and total wall time
   separately. Common proposals and fresh fits prevent an RNG/cache confound.
   Gate: at least one additional valid proposal within equal search budget,
   successful finalist confirmation, and independent confirmation logloss no
   worse than control by >1%. No blind fixed-cap increase.
2. **H2: inexpensive initial models, fabert.** Evaluate scaling+logit,
   scaling+LightGBM and scaling+CatBoost against the native five-node stack.
   Select by the selection partition only. Gate: selected simple model has
   >=25% lower measured fit+prediction cost and confirmation loss no worse
   than stack by >1%. Subsequent full candidate changes initial-model choice,
   not simultaneous budget/search-space/ensemble defaults.
3. **H3: coupled boosting horizon, Covertype.** Fixed prospective pairs
   (100,.1), (150,.1), (300,.05), (450,1/30), with common tree complexity,
   early stopping and seed. This is not a repeat of the old 100/400 stack
   grids. Select on selection data; preserve actual fitted rounds. Gate:
   >=1% confirmation logloss reduction over (100,.1), valid probabilities and
   projected full refit within the hour. A full candidate uses the coupled
   search policy, not a blanket 400-tree default.
4. **H4: stacking/probability quality, fabert.** Same base models and regularized
   logistic meta learner: in-sample versus three-fold OOF meta features;
   also evaluate fixed equal-weight blending. Separately fit temperature on
   selection predictions only, using the existing experimental calibrator.
   Gate per intervention: >=1% confirmation loss improvement and measured
   cost consistent with a 1h budget. At most one full candidate: largest
   selection improvement among interventions that pass their independent
   confirmation gate; deterministic tie order OOF, blending, temperature.
   Report the selection step and its limits; no generalization claim from
   this single screening fold.
5. **H5: final refit reserve, Dionis.** Existing tested opt-in
   final_fit_use_remaining_time=true versus false, on fresh fold6. Previous
   positive folds justify this prospective full confirmation after the
   budget/refit and runtime contract tests. This is the only direction whose
   gate does not require new model screening. Audit selected graph, successful
   full refit, fallback, complete job budget and quality; retain opt-in unless
   wider evidence later supports changing defaults.
6. **H6: categorical schema, fabert.** Reproduce unknown-category failure with
   tiny real XGBoost fits; train-fitted pandas categories map unseen values
   to missing, while known categories retain codes. Verify eval/predict,
   serialization, schema mismatch rejection and numerical/regression behavior.
   Then test on training-only fabert data. Gate: reproducible baseline failure
   resolved by candidate without numerical regressions; actual FEDOT wrapper
   integration must pass before any full candidate. A stand-alone pandas
   demonstration is insufficient.

## Stop and reporting rules

Stop a direction at a failed mechanism/quality/budget gate; retain its evidence.
Do not spend a full run merely to obtain missing historical artifacts. Report
each direction as not started, active, passed, negative, failed or blocked.
No statistical/general improvement claim from one fold. After audited jobs,
commit/push evidence and explicitly list uncompleted work. No scheduler has
been created for this study.

## Frozen mechanism details (before the first model screen)

H1 uses the same ordered CatBoost proposals on both sides: colsample_bylevel
0.7, colsample_bylevel0.4, depth4, trees1500, and (learning_rate0.05,trees1800).
Other parameters remain native. Each side has900s search including its fresh
initial CV; a new trial is admitted only if its calibrated allowance fits.
The allowance is1.3 times the initial fresh whole-process cost at that side's
fidelity. Both selected finalists receive fresh three-fold confirmation and
a refit on the same80% outer-training rows before scoring the untouched20%
confirmation partition. This first policy screen isolates the search fidelity;
fresh timing calibration is common, not claimed as an independently tested
quality improvement. Each whole evaluation/refit has a600s hard bound.

H4 uses exactly two base models (native CatBoost and LightGBM), with identical
full-fit base predictions for the in-sample, OOF and equal-weight blend controls.
OOF adds three internal fits per base; all six costs count. The meta learner is
logistic regression C1/max_iter1000, seed104735. Calibration acts on the
in-sample stack and uses selection labels only. These custom two-base controls
are distinct from H2's native five-node stack. H3 additionally requires its
linear full-data fit projection to remain below324s before a full-run policy
is considered; this projection is not proof of actual full-refit feasibility.
